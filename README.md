# Textperts — ISM 6564, Assignment 9

## What this is            
This project implements a multi-agent retail support and warehouse management architecture using the Agent2Agent (A2A) protocol. The system consists of two agents:
1. **Support Assistant (Orchestrator):** Interacts with signed-in Northwind Outfitters customers to answer policy/order questions, initiate returns, hand off tickets to human agents, and coordinate item exchanges.
2. **Warehouse Agent (Specialist):** Operates as an independent A2A JSON-RPC service handling warehouse inventory lookups and item reservations without direct access to customer or order databases.
